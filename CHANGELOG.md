## [1.0.0] - 2026-08-04

### Added

- **Cryptocurrency Dashboard:** Real-time crypto market table displaying current prices, 24-hour price variations, and market capitalization.
- **CoinGecko API Integration:** Asynchronous data fetching from the CoinGecko public REST API to retrieve updated market metrics.
- **Interactive Details Modal:** Dynamic modal component providing extended information and metrics for any selected cryptocurrency.
- **End-to-End Testing Suite:** Comprehensive automated E2E tests built with Playwright covering table rendering, user navigation, and modal interaction.
- **Interactive Test Runner:** Added dedicated NPM scripts (`test:e2e:ui`) to run tests using Playwright's interactive UI mode for enhanced debugging.
- **Project Documentation & Licensing:** Complete setup with a detailed `README.md`, standard MIT `LICENSE`, and project architecture specs.
